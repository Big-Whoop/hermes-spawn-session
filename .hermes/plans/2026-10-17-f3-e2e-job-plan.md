built from the exact live image, without touching `/opt/data`, the live Deployment, or Peter's Desktop.

## Run script (inside the Job)
1. `hermes plugins validate --install-deps --json $PLUGIN_DIR` (fresh venv → catches undeclared deps).
2. `hermes plugins install <git-url> --ref $PLUGIN_REF --enable --yes-deps`.
3. `hermes serve` in background; wait for readiness; assert no `Failed to load plugin`; probe `/api/plugins/<id>/`.
4. Backend live checks (`scripts/live_test.py`, `live_report_test.py`).
5. `Xvfb :99 &` then Playwright `_electron` specs (serial) against the backend via
   `HERMES_DESKTOP_REMOTE_URL`/`_TOKEN`; enable the opt-in desktop half (mechanism unverified — risk R2).
6. JUnit + screenshots + traces → `/workspace/…/e2e-runs/<plugin>/<ts>/` (private; traces may hold tokens).

- R4 Hermes Desktop v0.22.2 under Playwright in the pod: only a toy Electron was proven.
